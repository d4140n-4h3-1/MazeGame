# SYSTEM LATIN
## Expanded Machine Dictionary

System Latin is a machine-oriented constructed language based primarily on Latin.

### Design Principles

1. Latin is the primary lexical and grammatical source.
2. Classical Latin provides the structural baseline.
3. Neo-Latin is permitted for modern technological concepts.
4. Greek may supply specialized technical roots where Latin is inadequate.
5. System Latin may deliberately regularize or coin forms for machine use.
6. English-recognizable cognates are preferred when practical.
7. Commands generally use imperative forms.
8. Machine states commonly use neuter forms.
9. Non-biological programs, processes, objects, and system entities may receive neuter adjective/participle agreement as a System Latin convention.
10. Context is important, but messages should remain explicit enough to be understood.
11. Repeated contextual exposure is part of the intended learning experience.

- **servitor**

# XLI. DESIGN NOTE

System Latin deliberately creates a spectrum of recognizability.

## Immediately recognizable

**Termina** → terminate  
**Confirmatum** → confirmed  
**Detectum** → detected  
**Processus** → process  
**Systema** → system  
**Patrōlium** → patrol  
**Transmite** → transmit  
**Communica** → communicate  

## Recognizable after exposure

**Retrahe** → retract → withdraw  
**Progredere** → progress → proceed  
**Periculum** → peril → danger  
**Securitas** → security  
**Potentia** → potent / power  
**Auctoritas** → authority  
**Reclude** → reclose / unlock  

## Learned through repetition

**Telos** → objective  
**Hostis** → enemy  
**Zeto** → search  
**Patrōlium** → patrol  
**Intrusor** → intruder  
**Nuntius** → message  
**Iter** → route  
**Locus** → location  

The player does not need to formally study System Latin to understand it.

Repeated situations should teach the vocabulary naturally.

For example:

**Hostis detectum.**  
Enemy detected.

**Hostis appropinquat.**  
Enemy approaching.

**Defende.**  
Defend.

**Hostis deletum.**  
Enemy destroyed.

**Resume patrōlium.**

Through repetition, the player gradually learns:

- **hostis** = enemy
- **detectum** = detected
- **appropinquat** = approaching
- **defende** = defend
- **deletum** = destroyed
- **resume** = resume
- **patrōlium** = patrol

This is an intentional gameplay feature of System Latin.
